# Gecos Theme
**Version:** 1.0.0

This plugin changes the Kanboard interface to a more modern and user-friendly design, specifically adapted for Gecos.

## Author
- laimeilleurzamis
- License MIT

## Features
This plugin completely revamps the visual experience and adds several functional improvements:
- **Modernized UI:** Overrides default styles with a clean, pastel blue theme featuring rounded corners, soft shadows, and improved typography.
- **Improved Layouts:** Introduces sticky sidebars for the Dashboard and User Profile pages to maintain navigation visibility while scrolling.
- **Card-Style Task Views:** Transforms the traditional task list into a modern, card-based layout with enhanced visual hierarchy.
- **Custom Task Reordering:** Allows users to sort and reorder tasks within columns based on their creation date via a custom controller.
- **Interactive Dropdowns & AJAX:** Integrates dynamic dropdown menus on task cards to quickly update priorities and move tasks between columns without reloading the page.
- **Custom Branding:** Replaces the default Kanboard branding with the Gecos logo and custom SVG favicons.
- **Refined Task Creation:** Simplifies the task creation and modification forms with better spacing, modern input fields, and custom column layouts.

## Requirements
- Kanboard >= 1.0.35

## Installation
You have the choice between 3 methods:

1. Install the plugin from the Kanboard plugin manager in one click.
2. Download the zip file and decompress everything under the directory `plugins/GecosTheme`.
3. Clone this repository into the folder `plugins/GecosTheme`.

> **Note:** The plugin folder is case-sensitive.
